01. Início de Dia

Garanta que está no repo correto. pwd mostra a pasta. O VS Code às vezes abre RISO; o repo é RISO/riso.

1. Verificar a pasta
pwd
cd riso
2. Voltar para a branch principal
git checkout main

Sala limpa do projeto.

3. Puxar novidades
git pull origin main

Sincroniza o Mac com o site oficial.

04. Botão de Pânico

Caso 1 — limpar alterações não salvas
git restore .

Descarta edições do VS Code sem apagar a branch.

Caso 2 — apagar a branch com erro
git checkout main
git branch -D nome-da-branch-com-erro

Volta para a main e destrói a branch de teste.

02. Nova Tarefa

1. Criar e entrar na branch de testes
git checkout -b nome-da-sua-branch

Exemplo: git checkout -b novo-cardapio-sobremesas

Agora basta abrir o arquivo correto e começar a trabalhar nas mudanças.

05. Comandos úteis

Histórico recente
git log --oneline -n 5
Branches e SSH
git branch
ssh -T git@github.com
Remoto e gaveta
git fetch --prune
git stash
git stash pop
Limpar branches já mergeadas
git limpar

Preserva a atual, main, master e develop. Usa -d (seguro), não -D.

03. Salvar e enviar

Antes de git add ou commit, salve no VS Code com Command+S. Sem isso o Git não vê o arquivo.

1. Verificar
git status
2. Preparar
git add .
3. Commit
git commit -m "Explicação da alteração"
4. Enviar
git push origin nome-da-sua-branch

06. Regra de ouro

Nunca edite na

main

Ela é o site ao vivo.

• Crie sempre uma branch: trabalhe 100% isolado.

• Publicação segura: envie o

git push

e abra o Pull Request no navegador para o Go-Live.

Dicionário Git

Clique no título do verbete. A busca também filtra esta lista.

pwd — onde eu estou?

Mostra o caminho da pasta atual do terminal. Se não terminar em /riso, rode cd riso antes de qualquer Git.

git checkout main — sala limpa

Troca para a main. Use no começo do dia e depois de terminar (ou cancelar) uma tarefa.

Equivalente moderno: git switch main.

git pull origin main — trazer o GitHub

origin é o apelido do remoto. main é a branch. Faça isso antes de criar uma branch nova.

git checkout -b — criar e entrar

A flag -b cria a branch e já entra nela.

git checkout -b novo-cardapio-sobremesas

Equivalente moderno: git switch -c nome.

git status — o que mudou?

Lista arquivos novos e modificados. Se a lista vier vazia depois de editar, faltou Command+S.

git add . — preparar tudo

O ponto . = todos os arquivos desta pasta. Ainda não grava o histórico — só coloca no balcão (staging).

git commit -m — checkpoint

-m coloca a mensagem na mesma linha.

git commit -m "Atualiza sobremesas do cardápio de sábado"
git push origin nome — enviar

Sobe a branch. A main do site ainda não muda. Depois: Pull Request no navegador.

git restore . — descartar o não commitado

Joga fora edições locais que ainda não viraram commit. Não apaga a branch.

-d vs -D
  • -d — apaga só se já foi mergeada. Seguro. É o que o git limpar usa.
  • -D — apaga à força. Botão de pânico.
git log --oneline -n 5
  • --oneline — um commit por linha (hash curto + mensagem).
  • -n 5 — só os 5 mais recentes.
git fetch --prune

Atualiza o mapa do GitHub e remove no Mac as refs de branches que já não existem lá. Não mexe nos seus arquivos.

git stash / git stash pop

stash guarda mudanças sem commit numa gaveta. stash pop devolve. Útil para trocar de branch no meio de uma edição.

git limpar — o seu alias

Apaga branches já mergeadas. Preserva a atual, main, master e develop.

git branch --merged | grep -v '^\*' | grep -vE '^(main|master|develop)$' | xargs git branch -d
  1. --merged lista o que já entrou em outra branch.
  2. grep -v '^\*' tira a branch atual.
  3. O segundo grep protege main / master / develop.
  4. xargs git branch -d apaga o resto, só se estiver mergeado.

Se o alias ainda não existir nesta máquina:

git config --global alias.limpar '!git branch --merged | grep -v "^\\*" | grep -vE "^(main|master|develop)$" | xargs git branch -d'
ssh -T git@github.com

Testa a chave SSH. Resposta boa: “Hi usuario! You've successfully authenticated…”. -T = teste sem abrir sessão.

origin

Apelido padrão do repositório no GitHub. Ver endereço: git remote -v.

main

No Riso, é o que o visitante vê em riso.art.br. Não commite nela no dia a dia.
